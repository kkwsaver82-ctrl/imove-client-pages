# 개인정보 보호 가이드

이 프로젝트는 아동의 재활, 진단, 기능 수준, 수술 이력, 보호자 안내 정보가 포함될 수 있습니다.
따라서 운영 전 아래 원칙을 지켜야 합니다.

## 권장

- 실명 대신 코드 사용: `IM-2026-001`, `김○○`
- HTML 파일명에도 실명/진단명 넣지 않기
- 사진/X-ray는 이름, 생년월일, 병원번호, 촬영번호 제거 후 사용
- 보호자 전달은 PDF 또는 제한 공유 링크 우선
- GitHub 저장소는 private으로 운영

## 비추천

- GitHub Pages 공개 링크로 고객별 페이지 발송
- 파일명에 `홍길동_뇌성마비_GMFCS3.html`처럼 민감정보 포함
- 검색엔진 차단만 믿고 공개 웹에 업로드

## 보호자 안내 문구 예시

이 페이지는 센터 상담 내용을 보호자가 쉽게 확인하도록 정리한 참고 자료입니다.
진단, 처방, 수술 여부 결정은 담당 전문의의 진료를 기준으로 합니다.
링크와 파일은 외부에 공유하지 말아 주세요.

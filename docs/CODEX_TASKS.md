# Codex 작업 지시서

## 프로젝트 목표

아동 운동발달센터에서 보호자에게 보낼 개별 관리 페이지를 HTML 단일 파일로 생성하고 관리한다.
사용자는 코딩 비전문가이므로, 데이터 입력과 고객별 복사가 쉬워야 한다.

## 현재 구현된 기능

- 고객별 운동발달 관리 페이지
- 보호자 안내 문구
- 기본 정보, 고관절·척추 감시, 관리 목표, 가정운동, 방문 기록, 보호자 메시지 섹션
- 좌측 HTML 코드 / 우측 실시간 미리보기 편집기
- GPT 수정 프롬프트 복사 기능
- HTML 다운로드 기능
- 깨진 HTML 문자 자동복구 기능
- overview 축소 보기

## 우선 개선 요청

1. 고객용 페이지와 편집기용 페이지를 명확히 분리한다.
2. `CLIENT_DATA`만 바꿔도 모든 표시가 바뀌도록 유지한다.
3. 고객용 페이지에는 관리코드, 인쇄/PDF 저장, GPT 수정방법 버튼을 기본적으로 숨긴다.
4. 기본 정보는 GMFCS, 키/몸무게, 연령대, 경직 정도 4개만 표시한다.
5. 사진 업로드 또는 이미지 삽입 기능을 추가할 수 있는 구조를 제안한다.
6. 고객별 HTML 파일을 자동 생성할 수 있는 CSV/JSON 기반 구조를 장기 과제로 제안한다.

## 금지/주의

- 개인정보가 노출되는 예시 실명 사용 금지
- GitHub Pages 공개 배포를 기본값으로 제안하지 말 것
- 보호자에게 진단/치료 결정을 단정하는 문구 사용 금지
- 의료진 상담을 대체한다는 표현 금지

## Codex에게 줄 개별 작업 예시

```text
src/client_management_page_overview.html을 기준으로, X-ray 이미지 표시 섹션을 추가해줘.
이미지는 선택 사항이며, CLIENT_DATA.images.xrayUrl이 비어 있으면 섹션이 보이지 않게 해줘.
디자인 톤은 기존 카드 스타일을 유지해줘.
```

```text
src/live_html_editor_overview.html에 '사진 영역 추가' 샘플 버튼을 만들어줘.
실제 서버 업로드는 하지 말고, base64 미리보기 또는 로컬 파일 선택 미리보기만 가능하게 해줘.
```
